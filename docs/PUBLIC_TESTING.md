## 试用和反馈

两站域名不同，浏览器书库和接口配置不会自动共享。先在原站导出备份，需要时在公测站导入；不要清空原站数据。

发现问题可在[公测库 Issues](https://github.com/yydcm-129/Moyun/issues)反馈。请写清：手机／平板／电脑、系统和浏览器、横竖屏、复现步骤、预期与实际情况、明暗主题、是否有 MOD，以及测试时的候选提交。布局问题附全屏截图并说明工具栏／键盘是否打开，遮去密钥和私人作品。

本轮 v0.0.20 只更新公测：原文父子块、关键词与外部向量混合召回、可选重排、预算与摘要设置、旧记忆状态、分记录保存、角色分类和批量修改。新增1128公告，既有1116及已读历史保留。准确上线状态见[本轮回执](V0.0.20_RELEASE_REPORT.md)，范围与限制见[检测报告](V0.0.20_TEST_REPORT.md)；正式站继续保留已发布版本。公测网页顶部及浏览器标题显示公测身份，「全局设置 → 关于」显示当前站点、正式／公测入口及反馈链接。

关键词与本地排序可在浏览器工作；向量索引、查询与外部重排会请求作者配置的API，可能付费且需要服务商允许网页跨域。先用备份测试熟悉的旧事实，核对“上次召回”与实际写作结果，再决定是否开启付费维护。自动总结关闭不会擅自补录；旧记录待核对时先检查原文，不按猜测批量确认。

角色分类在角色工作台，可组合搜索与势力筛选。批量修改先选角色、选字段、预览旧值和新值，再应用；最近一次可撤销，但后续手工修改冲突时不会强行覆盖。新快照开关只影响后续请求，旧快照可在快照历史手动清理。

## 每轮固定核对（含手机与平板）

1. 二轮／三轮补写开关打开、关闭均居中，轨道不变形，点边缘也能操作。
2. 全局设置长内容滚动时，分类栏始终在标题下方；搜索、分类切换和底部完成按钮可用。
3. 手机和平板打开／收起浏览器工具栏、弹出／关闭键盘、切换横竖屏后，生成和完成按钮仍可见可点；正文能读到最后一段，不用缩放页面。平板保留双栏，电脑布局无多余底部空白。
4. 从公测仓库 README、About 的网站链接进入的都是公测站，顶部显示公测身份。「关于」的站点说明和链接准确；公测反馈链接可用。正式站不显示公测标识。
5. 维护者每次执行线上门禁 `npm run gate:release`，保留两站独立的文件指纹、手机和平板交互证据及 Pages 提交回执。旧书记忆与快照等本轮功能按专项报告回归，不能用布局检查代替数据检查。

开发侧已有隔离浏览器与可视区模拟证据，不能代替 iOS 和各厂商真机验证。维护者记录反馈结果和用户对候选 SHA 的明确确认后，后续候选才可转正式。执行步骤见[部署说明](DEPLOYMENT.md)。
