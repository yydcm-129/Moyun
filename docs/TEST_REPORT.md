## 已知风险与未完成验证

1. 真实 AI API、生图 API、NAI 5 返回图片和超长正文评论生成需要用户配置的在线服务，不能仅凭静态构建判定成功。
2. 自动填充的部分路径采用本地提取与保守更新；若要求“每个空字段都必须由 AI 自动补齐”，需要另做端到端测试和产品决策。
3. Tailwind CDN 生产警告仍存在；改为本地构建需要引入依赖，必须单独获得授权。
4. Impeccable 审计依赖不完整，视觉审计结果应结合真实浏览器截图，而不能只看降级脚本。

## 下一轮测试门禁

修改运行时代码后至少执行构建、语法和差异检查；涉及 UI 时还要在 Edge 真实页面检查桌面和 `390×844` 移动端，确认无水平溢出、资源破损、控制台错误和按钮裁切。涉及 AI/API 时必须记录请求模式、超时、流式状态和错误处理结果，不要把“按钮存在”当成接口成功。
