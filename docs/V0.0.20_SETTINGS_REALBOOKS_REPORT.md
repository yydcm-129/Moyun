## 问题、要求与验收

### 设置分区

**问题：** 补写、阅读导航、评论、输出显示和任务模型分配挤在上下文页，难以分辨哪些设置改变输入资料。

**要求：** 在上下文与书籍提示词之间加入“辅助功能”，移动上述设置及时间线自动补录，保留所有原设置键、值与保存方式。上下文保留参考资料、记忆、章节范围与字数预算。搜索、团队开书与连接中心跳转同步更新。

**验收：** 320／360／768／1024 触屏平板／1280 电脑、明暗主题下检查新分区、搜索实际点击定位、44px 点击区、保存和刷新；旧功能继续跑完整浏览器门禁。

### 生图世界书

**问题：** 正文插图的格式、标签优先级、权重和角色一致性写死在内部；两个标签提取模板入口分散。

**要求：** 生图页尾开放格式、画面优先级、标签、权重、一致性、自定义补充六段规则，以及使用规则／带入角色外貌两个开关。关闭生图时也可编辑，清空表示不发送该项，可逐项恢复。规则挂在当前书的 novel.imageWorldbook，随原有 IndexedDB、完整书籍备份保存；原插图／立绘标签提取模板仍为全局设置，集中在其下方。未引入 RPHUB 的完整框架或额外数据库。

**验收：** 默认输出与旧版逐字一致；真实输入、自定义、清空、开关、恢复、切书、刷新、备份导回均检查；捕获写作请求确认只出现一次自定义指令，不向真实生图服务发请求。

交付 review 补回了两个全局标签模板原有的“恢复默认”按钮，复用原函数；修复旧加载逻辑把空字符串当成未配置的问题。浏览器通过清空两项 → 保存 → 刷新仍为空 → 分别点击恢复 → 确认默认内容，避免搬动入口时丢掉原有操作。

### 独立向量连接与使用说明

**问题：** 向量接口绑定默认写作连接，旧按钮混合执行总结、索引和合并。只有 embedding 的服务无法独立完成索引；旧公告没有完整操作路线。

**要求：** 增强模式提供独立向量连接、可手填完整模型名、增量建索引及确认后全部重建。连接中心识别 embedding 模型并使用 /embeddings 测试。只建索引不调用总结、写作或重排。公告新增同日独立已读标识，说明连接中心 → 记忆库 → 向量连接／模型 → 建索引 → 查看上次召回；保留旧公告。

**验收：** 测试连接、保存配置、只建索引、不重复请求、写作连接不变、刷新持久化；真实调用只限授权服务和模型，每次发请求前写入本机账本，失败也计数，硬上限 1000 次。

## 实测发现与修复

第一轮 8 个改写问题有 1 个虽命中章节，却只带回场景描写，没有后段事件结果。父块只覆盖附近三段，跨段因果仍可能丢失。现在片段命中后补入该章有效记忆，每章只带一次，过期／未核对记忆不参与，原预算不变。保留修复前失败，用同样问题和真实查询复验；未增加答案专用关键词或规则。

测试端曾把 Vue 响应式数组直接交给 CDP 保存，得到空对象缓存；大数组一次回传也出现 CDP 超时。已改为每批 50 个块的 JSON 字符串读取。额外索引请求全部计入账本，不从统计中扣除，不算产品增量索引失败。产品内部连续两次增量建立另有零新增请求断言。

完整门禁第一次在阅读导航测试失败：旧脚本仍打开 context，实际控制已移入 auxiliary，导致隐藏控件高度为零。原失败日志和断言保留，随后中止该批次，不能计为通过；同步修正旧 v18 开关、模块跳转及首字超时的测试入口，点击、尺寸与内容断言保持不变。最终版本重新运行完整门禁。

第二次完整门禁发现两处公告用例仍要求旧公告正文；改为验证新版记忆指南，保留标题日期、刷新已读、边界和真实点击要求。停止补录用例原来检查整个面板是否包含“停止”，新增说明中的“可随时停止”触发误判；改为检查停止按钮确实消失，运行状态、取消后条数和晚到响应不写入的断言不变。平板开关曾在弹窗缩放期间测得 43.9258px；现按 Vue 更新、两帧和实际动画完成后测量，仍要求轨道精确 44×24、点击区至少 44px，没有放宽尺寸。

后续完整运行中，v18 的 Enter 搜索跳转在分区、清空和失焦均正确时，目标高亮仍因固定 180ms 等待出现偶发失败。产品在 nextTick 后的 requestAnimationFrame 加高亮；测试现在同样等待 Vue 更新与渲染帧，再在浏览器内立即读取高亮状态，不以延长固定睡眠或重试忽略失败。

## 边界与回滚

真实服务仅覆盖一个 OpenAI 兼容向量服务和 12 章抽样，不代表整本任意问题均可召回，也不代表写作模型一定正确使用事实。没有真实调用总结、写作、生图或外部重排；这些链路为本地 mock。未验证 Gemini 原生向量、其他服务商、iOS/Safari 或厂商真机。47 条来源缺失记忆保留，但没有自动找回来源。

最大剩余问题是“检索到章节”和“事实足以回答”并不等同。本轮修复一个真实跨段遗漏，仍需公测收集更多改写问题，不能把 8 个样例等同长期效果保证。长书全量索引费用与延迟仍需按实际模型和书库测量。

代码回退到前述备份分支；降级前先导出当前完整书籍。新规则是书内可选字段，旧版会忽略其编辑能力。旧 library_v6 仍仅是迁移前快照，不能替代迁移后的新创作数据；禁止删除 manifest 或清空站点数据。

中止失败批次时已停止对应隔离浏览器进程树。清理其临时资料夹的命令被自动安全检查拒绝，因此该目录保留；没有改动日常浏览器资料，也没有为清理绕过检查。
